# services/

Les services récupèrent et gèrent les données du site (films, séances, réservations, boutique, avis).

- `reservation-en-cours.ts` : garde les places et les snacks choisis pendant le passage
  Réservation → Paiement → Confirmation.

Les services de données seront ajoutés quand on aura choisi la source des données
(fausse API en JSON ou petit backend).
