# images/

Images du site. Chaque fichier porte le nom du film en minuscules, avec des tirets
(ex. `project-hail-mary.jpeg`), pour retrouver facilement l'affiche et la photo d'un même film.

- `affiches/` : affiches verticales des films (cartes, fiche film, récapitulatifs).
- `hero/` : grandes photos horizontales (haut de la fiche film, slides de l'accueil).
  Largeur conseillée : 1920 px, poids < 500 Ko.

Dans le code, le chemin commence à `images/` : `<img src="images/affiches/whiplash.jpeg">`.
